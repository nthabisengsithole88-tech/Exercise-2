# Exercise-2
Completed a hands-on SQL exercise focusing on aggregate functions, filtering, grouping, and data analysis.
This repository contains my solutions to a hands-on SQL exercise focused on building foundational data analysis skills using aggregate functions and operators. The exercise is based on practical scenarios involving multiple tables such as students, courses, enrollments, salaries, and projects, helping to simulate real-world data analysis tasks.

Throughout this exercise, I practiced key SQL concepts including aggregate functions like COUNT, SUM, AVG, MIN, and MAX, as well as data filtering using WHERE, BETWEEN, IN, AND, OR, and NOT. I also worked with GROUP BY to organize data and HAVING to filter grouped results, along with ORDER BY and LIMIT to sort and refine outputs. Additionally, I used aliases to improve query readability and match expected output formats.

The exercise consists of 15 structured queries that cover data exploration, aggregation, grouping, and conditional logic. Each task required careful thinking to both write the correct SQL statement and predict the expected output, reinforcing a deeper understanding of how SQL queries work.

By completing this exercise, I strengthened my ability to write efficient SQL queries, analyze structured datasets, and apply aggregation and grouping techniques in practical contexts. All work was completed manually as part of a pen-and-paper approach to improve accuracy and reinforce core SQL fundamentals.
